Información Básica

Conceptos esenciales de arquitectura, software libre y administración del sistema.

01. Kernel Linux y Filosofía Libre

Creado por Linus Torvalds en 1991, Linux es el núcleo (kernel) encargado de gestionar el hardware, la memoria RAM, los procesos y los dispositivos. Combinado con las herramientas del proyecto GNU, conforma un sistema operativo estable, seguro y bajo licencia GPL que permite estudiar, modificar y redistribuir su código fuente.

02. Distribuciones Principales

El ecosistema se organiza en distribuciones adaptadas a distintos propósitos. Destacan familias como Debian y Ubuntu (ideales para servidores web, DNS y uso general mediante paquetes .deb), Red Hat / Fedora (entornos corporativos .rpm) y Arch Linux (personalización avanzada).

03. Jerarquía de Directorios (FHS)

A diferencia de otros sistemas, Linux organiza todo bajo un único árbol que parte de la raíz /. Directorios críticos incluyen /etc para archivos de configuración del sistema, /var/www para servidores web, /home para datos de usuarios y /var/log para registros de auditoría.

Problemas y Soluciones

Resolución de incidencias frecuentes en la administración de sistemas y servidores Linux.

Problema #1: Seguridad y Accesos

Error "Permission Denied" en archivos o scripts

Al intentar ejecutar un script en Bash o subir archivos mediante FTP/SFTP a un directorio del servidor web, el sistema bloquea la acción debido a restricciones estrictas de propietario o falta de permisos de ejecución.

Solución Técnica

Ajuste de permisos y propietarios

Utiliza chmod +x archivo.sh para otorgar permisos de ejecución, o asigna los privilegios estándar (755 para carpetas y 644 para archivos). Si el propietario es incorrecto, reasígnalo con sudo chown -R usuario:grupo /ruta.

Problema #2: Gestión de Paquetes

Repositorios obsoletos o dependencias rotas

Al ejecutar apt update o instalar servicios como Apache o BIND9, el gestor devuelve errores 404, fallos de firma GPG o paquetes bloqueados que impiden actualizar el sistema operativo.

Solución Técnica

Reconstrucción de índices y reparación

Verifica las URLs de los espejos oficiales dentro de /etc/apt/sources.list, limpia la caché local con sudo apt clean y fuerza la reparación de dependencias rotas ejecutando sudo apt --fix-broken install seguido de una actualización limpia.

Problema #3: Redes y Demonios

Servicio activo localmente pero inaccesible en red

Un servidor web, FTP o DNS funciona dentro de la máquina local, pero los clientes externos no logran conectarse debido a bloqueos del cortafuegos o interfaces configuradas únicamente en loopback.

Solución Técnica

Diagnóstico de puertos y reglas de Firewall

Comprueba en qué interfaz escucha el servicio con ss -tulnp para asegurar que esté vinculado a la IP de red (0.0.0.0) y habilita el tráfico entrante en el cortafuegos mediante sudo ufw allow puerto/tcp.
